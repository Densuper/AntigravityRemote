# Contributing to Antigravity Remote

Thank you for your interest in contributing to **Antigravity Remote**! We welcome contributions, bug reports, feature requests, and pull requests from the developer community.

---

## Code of Conduct

Please maintain a respectful, welcoming, and harassment-free environment when interacting with other contributors and maintainers.

---

## How to Contribute

### 1. Reporting Bugs
- Search existing issues before creating a new one to avoid duplicates.
- Provide detailed steps to reproduce the bug, including your Android OS version, device model, and Antigravity IDE version.
- Include log snippets or stack traces if available.

### 2. Suggesting Features
- Open an issue describing your proposed feature and rationale.
- Explain how the change improves the user workflow when remotely interacting with Antigravity AI agents.

### 3. Pull Requests
1. **Fork** the repository and create a new feature branch (`git checkout -b feature/amazing-feature`).
2. Follow Android and Kotlin official style guidelines.
3. Verify that code builds cleanly (`./gradlew assembleDebug` or `gradlew.bat assembleDebug`).
4. Ensure no secret keys, keystores, or private tokens are committed.
5. Commit your changes with clear, descriptive commit messages.
6. Push to your branch and open a Pull Request against `main`.

---

## Development Environment Setup

- **IDE**: Android Studio Ladybug / Meerkat (or newer)
- **JDK**: Java 17 (Temurin / OpenJDK)
- **Min SDK**: API 26 (Android 8.0 Oreo)
- **Target / Compile SDK**: API 35 (Android 15)
- **Architecture**: Modern Android architecture with Jetpack Compose, Material 3, CameraX, BiometricPrompt, and Coroutines/Flow.
